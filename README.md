Формализация условия: дан ор граф с весами на ребрах, возможным требованием наличия артефакта (множество required предметов мы храним в виде bitmask). в первых двух пунктах требуется определить, сможем ли мы вообще дойти до одного из выходов, в вттором - минимизировать время, при этом мы можем выбирать время начала, а также ждать, находясь в вершине. для решения 1-2 мы используем алг Дейкстры, 

Решение: введем: (v, mask), обозначающее текущую вершину и маску собранных на пути предметов. множество допустимых отрезков старта задается двумя числами [lo, hi]. пятерка (v, mask, t, lo, hi) задает состояние, описавающее, что можно оказаться в вершине v, при этом собрав набор предметов mask за время t, достижимое при старте из отрезка [lo, hi]. мы хотим понять, когда состояние лучше другого, введем a.time <= b.time && a.lo <= b.lo && a.hi >= b.hi, то есть состояние a было не позже, при этом начальный отрезок не короче. для каждой пары (vertex, mask) храним набор попарно не доминирующих состояний. 

заметим, что переходы могут быть:
    1. (to, mask, t + d_e, lo, min(hi, D_e − t − d_e)), то есть пройти по рубру e
    2. (v, mask + {item}, max(t, l_i − hi), max(lo, l_i − t'), min(hi, r_i − t')), где t' = max(t, l_i − hi), то есть ообновить маску предметов, находясь в вершине v, так как мы хотим l_i <= s + t' <= r_i, чтобы попасть в допустимый отрезок, когда мы можем взять предмет из текущей вершины
